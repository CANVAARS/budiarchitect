budiarchitect.site x Nusacoin
Repositori ini berisi kode sumber untuk platform budiarchitect.site yang mengintegrasikan layanan visualisasi arsitektur & pemodelan 3D dengan ekosistem blockchain Nusacoin (nusacoin.org).

📌 Fitur Utama
Portofolio Arsitektur 3D: Menampilkan katalog desain rumah modern klasik, tipe 45, dan aset SketchUp.

Integrasi Nusacoin: Pembayaran jasa arsitektur dan pembelian lisensi desain menggunakan token/koin di jaringan Nusacoin.

Verifikasi Hak Cipta: Pencatatan hash model 3D ke dalam smart contract Nusacoin untuk pembuktian kepemilikan karya.

🛠️ Teknologi yang Digunakan
Frontend: Next.js / React, Tailwind CSS

Web3 Integration: Ethers.js / Viem

Blockchain Network: Nusacoin Mainnet (nusacoin.org)

Smart Contract: Solidity
